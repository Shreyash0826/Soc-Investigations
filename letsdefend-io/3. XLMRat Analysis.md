# SOC Incident Report: XLMRat Stager & AsyncRAT Execution

## 1. Scenario
**Alert:** Suspicious PowerShell Execution and Payload Retrieval  
**Host:** `WIN-INVESTIGATION`  
**Description:** A suspicious PowerShell execution was flagged after downloading a secondary payload (`mdm.jpg`) disguised as an image file from an external IP address (`45.126.209.4:222`).

---
## 2. Initial Triage
### First Steps & Rationale
Upon receiving the alert for suspicious PowerShell execution, the initial triage focused on isolating the scope of execution and identifying the source of external communication:
1. **Alert Details Review:** Checked the command line arguments of the PowerShell execution to identify obfuscation patterns (e.g., string replacement using `#` symbols).
2. **Network Connection Analysis:** Extracted the external C2 IP (`45.126.209.4:222`) and evaluated traffic indicators.
3. **Process Tree & Artifact Inspection:** Inspected the stager script (`mdm.jpg`) to verify how the payload was downloaded and executed in memory versus what was dropped to disk.

---
## 3. Investigation
### Evidence Gathered
* **Network Indicators:** Outbound connection traced to C2 infrastructure at `45.126.209.4:222` (Hosted by ReliableSite.Net).
* **Payload Analysis:** Reconstructed and hashed the secondary payload extracted from `mdm.jpg`, yielding SHA256: `1eb7b02e18f67420f42b1d94e74f3b6289d92672a0fb1786c30c03d68e81d798`.
* **Attribution & Metadata:** VirusTotal and PE header inspection identified the binary family as **AsyncRAT**, with a compilation timestamp of `2023-10-30 15:08`.
* **Execution & Persistence:** 
  * Leveraged .NET Reflection to hollow/inject code into the legitimate LOLBin: `C:\Windows\Microsoft.NET\Framework\v4.0.30319\RegSvcs.exe`.
  * Dropped persistence files (`Conted.ps1`, `Conted.bat`, `Conted.vbs`) into `C:\Users\Public\`, triggered via an "Update Edge" scheduled task.

---
## 4. Verdict
* **Verdict:** True Positive
* **Reasoning:** 
  1. The external communication points to a known malicious C2 infrastructure (`45.126.209.4:222`).
  2. The downloaded payload matches a known malware family (**AsyncRAT**) with verified hash signatures.
  3. The execution behavior leverages stealthy techniques like .NET Reflection through a LOLBin (`RegSvcs.exe`) and persistence configuration via scheduled tasks.
 
---
## 5. Action Taken

* **Containment:** Isolated the affected endpoint from the corporate network to block active C2 beaconing and stop potential lateral movement.
* **Eradication:** Terminated malicious processes tied to `RegSvcs.exe`, removed dropped persistence files (`Conted.ps1`, `Conted.bat`, `Conted.vbs`) from `C:\Users\Public\`, and deleted the rogue scheduled task ("Update Edge").
* **Escalation & Remediation:** Flagged the host for full forensic disk imaging, initiated forced credential rotations for compromised service accounts, and blacklisted the C2 IP (`45.126.209.4`) at the perimeter firewall.

* ---
## 6. Lessons Learned

* **Detection Gaps:** Basic static signature matching failed to flag the obfuscated stager disguised as an image file (`mdm.jpg`), highlighting reliance on runtime behavior rather than file extensions.
* **Recommendations & Hardening:** 
  1. Ensure PowerShell **Script Block Logging (Event ID 4104)** is globally enabled and actively monitored for string concatenation and obfuscation patterns.
  2. Implement strict endpoint monitoring for abnormal execution behavior involving .NET Framework binaries (e.g., `RegSvcs.exe` making outbound network connections).
  3. Restrict execution and write permissions in common staging directories like `C:\Users\Public\` via AppLocker or software restriction policies.
