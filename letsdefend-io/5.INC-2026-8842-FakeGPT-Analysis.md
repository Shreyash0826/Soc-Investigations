# Incident Investigation Report: Malicious Chrome Extension (FakeGPT)

**Incident Ref:** INC-2026-8842  
**Target Host/User:** Workstation-Finance-04 / Local User  

---

## 1. Scenario
**Alert:** High-Severity SOC Alert — *Suspicious Browser Extension Activity & Data Exfiltration*.  
A web browser process spawned abnormal network traffic towards an unclassified external domain (`Mo.Elshaheedy.com`), coupled with dynamic script generation and localized keystroke hook events inside Google Chrome.

---

## 2. Initial Triage
1. **Source Context:** Inspected local extension artifacts (`manifest.json`, `loader.js`, `app.js`) to evaluate permissions and entry points.
2. **Environmental Check:** Evaluated `loader.js` to identify sandbox evasion routines.
3. **Execution Context:** Analyzed `app.js` to inspect input form event listeners (`keydown`, `submit`) and outbound web requests.

---

## 3.Investigation & Evidence
A. Anti-Analysis & Sandbox Evasion
File & Location: loader.js (Line 6)
Logic: Checks if navigator.plugins.length === 0 or if navigator.userAgent contains HeadlessChrome.
Impact: If zero plugins are installed or a headless browser is detected, the script terminates execution to evade automated analysis.

B. Target Identification
File & Location: app.js (Line 9)
Logic: Target domain is Base64-encoded as "d3d3LmZhY2Vib29rLmNvbQ==".
Decoded Target: www.facebook.com

C. Keystroke Logging & Credential Interception
Event Hooks: Captures keydown events for keystroke tracking and submit events on forms.
Execution Flow: Triggers exfiltrateCredentials(username, password), which passes data to encryptPayload().
Encryption: Applies AES encryption to sensitive inputs before transmission.

D. Covert Network Exfiltration
File & Location: app.js (Lines 42-44)
Exfiltration Vector: Creates a dynamic image element (new Image()) and sets its source URL to:https://Mo.Elshaheedy.com/collect?data=[encrypted_data]
C2 Domain: Mo.Elshaheedy.com
Protocol/Method: Outbound HTTPS GET request disguised as an image fetch to bypass standard firewall filters.

E. Session Manipulation
Permission: Requested "cookies" in manifest.json.
Impact: Grants access to active session cookies and authentication tokens.

---

## 4. Verdict
**TRUE POSITIVE**  
The Chrome extension is a malicious credential harvester ("FakeGPT") designed to detect virtual environments, intercept keystrokes and form credentials on target platforms (`www.facebook.com`), encrypt payloads via AES, and exfiltrate sensitive data to `Mo.Elshaheedy.com` using covert HTTP GET requests disguised as image loads.

---

## 5. Action Taken
1. **Host Isolation:** Immediately isolated `Workstation-Finance-04` from the network to halt ongoing data exfiltration.
2. **Credential & Session Invalidation:** Triggered an enterprise-wide password reset for affected user accounts and revoked all active authentication session cookies.
3. **C2 Block:** Added `Mo.Elshaheedy.com` to edge firewall deny lists, web proxy blocklists, and DNS sinkholes.
4. **Remediation & Policy:** Removed the extension, wiped browser storage/cookies, and pushed a Chrome Enterprise Policy restricting unsigned third-party extension side-loading.

---

## 6. Lessons Learned & Detection Gaps
* **Detection Gap:** Standard outbound firewall rules permitted data exfiltration because payload data was appended as query parameters in standard HTTPS GET requests loading dynamic image assets.
* **Improvements:**
  * Enforce strict Google Chrome Enterprise Policies to block developer mode and side-loaded extension packages (`.crx` / unpacked directories).
  * Configure SIEM detection rules for high-frequency dynamic `<img>` DOM creations where destination URLs contain long query parameter payloads.
  * Audit extensions requesting high-risk combined permissions (e.g., `cookies` + broad host access `<all_urls>`).
