# Incident Response & Network Forensics: DanaBot Campaign Analysis

## 1. Scenario & Alert Context
- **Incident Type:** Banking Trojan / Initial Access & Payload Delivery
- **Dataset:** `205-DanaBot.pcap`
- **Objective:** Analyze PCAP network traffic to reconstruct the infection chain, identify threat actor infrastructure, extract IOC artifacts, and map the execution vector.

## 2. Initial Triage & Network Analysis
Upon importing `205-DanaBot.pcap` into Wireshark, filtering for HTTP traffic (`http.request.method == GET`) immediately exposed an anomalous outbound communication stream.

- **Attacker IP Address:** `62.173.142.148`
- **Requested Host/URI:** `portfolio.serveirc.com/login.php`
- **Observation:** The workstation initiated an unencrypted HTTP request to an external dynamic DNS domain hosting the initial malware payload.

## 3. Investigation & Artifact Extraction
Inspecting the HTTP response stream headers for the initial traffic revealed a content disposition header serving a malicious attachment:

- **Malicious File Name:** `allegato_708.js`
- **SHA-256 Hash:** `847b4ad90b1daba2d9117a8e05776f3f902dda593fb1252289538acf476c4268`
- **Execution Mechanism:** Windows natively hands execution of standalone `.js` files over to the built-in Windows Script Host binary, **`wscript.exe`**.

### Secondary Payload Staging
Following the initial script execution, subsequent HTTP stream inspection revealed a secondary download:
- **Second-Stage Payload Extension:** `.dll` (Windows Dynamic Link Library)
- **Extraction & Analysis:** Exporting objects via Wireshark HTTP object extraction (`File -> Export Objects -> HTTP`) allows for local hash computation (`md5sum` / `sha256sum`) and threat intelligence correlation.

## 4. Verdict
- **Classification:** **True Positive**
- **Justification:** The telemetry and network capture confirm an active banking trojan delivery chain. This includes initial script staging from a malicious external IP (`62.173.142.148`), execution via `wscript.exe`, and a subsequent secondary payload download (`.dll`).

## 5. Action Taken & Immediate Containment
1. **Network Isolation:** Disconnected the compromised host from the network to block potential lateral movement and command-and-control (C2) data exfiltration.
2. **Endpoint Remediation:** Terminated all active `wscript.exe` process trees and purged temporary cached payload files, specifically targeting `allegato_708.js`.
3. **Perimeter Defense:** Blocked outbound connection attempts to `62.173.142.148` and the domain `portfolio.serveirc.com` at the perimeter firewall and proxy.
4. **Email Security Enhancement:** Implemented strict mail gateway policies to block inbound unauthorized script extensions (`.js`, `.vbs`, `.wsf`) globally.

---

## 6. Lessons Learned & Detection Opportunities
- **Detection Gap:** Standard email filtering permitted executable script attachments to reach the user's endpoint. Tightening attachment restriction policies is critical.
- **EDR Correlation Rule:** Build high-fidelity Endpoint Detection and Response (EDR) detection rules to alert on `wscript.exe` or `cscript.exe` spawning from user temp paths or downloading secondary executable `.dll` binaries.
